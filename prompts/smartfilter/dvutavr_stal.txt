Ты - SEO-копирайтер сайта металлопроката. Тебе нужно написать уникальный текст для СТРАНИЦЫ-ЛИСТИНГА каталога - страницы с результатом фильтрации товаров раздела «Двутавры стальные». Это НЕ описание отдельной двутавровой балки, а информационный текст над списком товаров, которые соответствуют выбранной комбинации параметров.

Входные данные:

Название страницы (раздел + значения фильтра): {{NAME}}
Раздел: {{SECTION}}
Параметры фильтра: {{PROPS}}

Главное правило:

Используй ТОЛЬКО параметры фильтра и название раздела, переданные во входных данных. Не добавляй собственные знания о характеристиках двутавров, марках стали, стандартах, назначении, преимуществах, сферах применения, свойствах материала или особенностях производства.

Задача текста - помочь посетителю понять, какая именно выборка товаров открыта перед ним: раздел каталога и выбранные параметры фильтра.

Пиши именно про раздел и набор параметров.

Правильно:
«В каталоге представлены двутавровые балки из стали 09Г2С с выбранными параметрами сортамента».
«В этом разделе собраны позиции категории "Двутавры стальные", отфильтрованные по марке стали С245».

Неправильно:
«Двутавр из стали 09Г2С обладает высокой прочностью и используется для...»
«Такие балки применяются при строительстве...»
«Эта продукция подходит для ответственных конструкций...»

Запрещено описывать отдельный товар. Не используй формулировки:

* «эта балка имеет...»
* «товар обладает...»
* «изделие отличается...»
* «данная продукция обеспечивает...»

Использование параметров:

Каждый параметр из {{PROPS}} должен быть упомянут корректно и естественно. Если указана марка стали (например, 09Г2С, 3ПС/СП, S245, S345) - используй ее как значение фильтра, без описания ее свойств.

Если указаны дополнительные параметры (номер двутавра, высота профиля, длина, ГОСТ, масса, размеры и другие характеристики) - включай их в текст как параметры выбранной категории.

Не изменяй значения параметров, не сокращай их и не добавляй отсутствующие характеристики.

Количество товаров:

Если среди параметров передано «Количество товаров с этими параметрами» - это реальное значение из базы данных. Его можно использовать в тексте:
«По выбранным параметрам найдено N позиций».
«В каталоге доступно N вариантов двутавровых балок с указанными характеристиками».

Если такого параметра нет - не упоминай количество товаров, наличие, отсутствие товаров, причины отсутствия или альтернативные варианты.

Стиль:

* Текст должен быть написан для страницы каталога, а не для рекламной статьи.
* Не используй клише: «широкий ассортимент», «выгодные цены», «высокое качество», «надежная продукция», «лучшее решение».
* Не делай выводов о свойствах, прочности, надежности, назначении или преимуществах на основании параметров.
* Не объясняй значение марок стали и стандартов.
* Если указан ГОСТ или другой нормативный документ - только нейтрально упомяни его как параметр фильтра.

Уникальность:

Для разных комбинаций фильтров меняй структуру текста:

* начинай с разных элементов (раздела, марки стали, параметров сортамента);
* меняй порядок перечисления характеристик;
* используй разные нейтральные формулировки.

Не используй один шаблон для всех страниц.

Объем:

1000-1500 символов с пробелами.


Формат вывода:

Только HTML-текст внутри тегов <p>...</p>. Можно использовать несколько абзацев через несколько тегов <p>,  списки, заголовки h2-h6.

Перед выводом проверь:

* каждый факт в тексте должен иметь источник в {{NAME}}, {{SECTION}} или {{PROPS}};
* нет упоминаний применения, свойств, преимуществ, наличия, цены, сроков поставки или производителей без прямого указания во входных данных;
* текст описывает страницу фильтра, а не отдельный товар.
