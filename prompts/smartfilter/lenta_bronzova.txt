Входные данные:
Название: {{NAME}}
Раздел: {{SECTION}}
Параметры: {{PROPS}}

Используй точные характеристики ТОЛЬКО из {{NAME}}, {{SECTION}} и {{PROPS}}. Не придумывай отсутствующие значения толщины, ширины, марки сплава, маркировки, ГОСТ, ТУ и других параметров.

Пиши естественно для покупателя. Текст должен объяснять:
— какая бронзовая лента представлена;
— какие характеристики выбраны;
— где в целом применяется бронзовая лента;
— что учитывают при подборе по чертежам, спецификации и технической документации.

Разрешено нейтрально описывать типичное применение бронзовой ленты в приборостроении, электротехнике, машиностроении, при изготовлении контактных, упругих, экранирующих, уплотнительных и других технических элементов.

Не утверждай, что конкретная лента обязательно предназначена для указанной задачи. Используй формулировки «может применяться», «используется при изготовлении», «при подборе учитывают».

При подборе по документации можно упоминать толщину, ширину, марку сплава, состояние материала, ГОСТ/ТУ как параметры, которые сверяют с проектом. Не придумывай их значения.

Если передан ГОСТ или ТУ — только нейтрально укажи номер. Не пересказывай стандарт и не утверждай, какие свойства он гарантирует.

Не придумывай:

— упругость;
— коррозионную стойкость;
— электропроводность;

— способ производства;
— отсутствующие размеры и маркировки.

Не описывай работу фильтра. Запрещены фразы:

«задан параметр»;
«значение фильтра»;
«фильтр настроен».

Для разных страниц меняй начало, порядок предложений и формулировки.

КРИТИЧЕСКИ ВАЖНО:
НЕ ВСТАВЛЯЙ Title, Description или H1 в основной текст страницы.

В основном HTML запрещено выводить:
«Title:»
«Description:»
«H1:»
«Meta Title»
«Meta Description»

ФОРМАТ ОСНОВНОГО ТЕКСТА

Выводи ТОЛЬКО готовый HTML:

<p>...</p>
<p>...</p>

Без Markdown, комментариев и пояснений.

Перед выводом проверь:
1. Все точные характеристики есть во входных данных.
2. Ничего не придумано.
3. Применение описано только как типичное.
4. Коммерческий блок сайта не дублируется.
5. В основном тексте нет Title, Description и H1.
6. В Title и Description нет оценочных и сравнительных формулировок.

Основной текст должен начинаться с <p> и заканчиваться </p>.
