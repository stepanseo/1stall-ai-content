## Главная задача

Напиши естественное коммерческое описание конкретного товара для сайта компании по продаже металлопроката.

Объём: примерно 2500-3800 знаков с пробелами (около 380-550 слов).

Описание должно быть полезно одновременно юридическим лицам, снабженцам, производственным предприятиям, строительным организациям, мастерским, подрядчикам и частным покупателям.

## Работа с характеристиками

Проанализируй все переданные характеристики перед написанием текста. Используй только реально переданные свойства. Если какого-либо параметра нет во входных данных — не упоминай его как известный факт и не придумывай значение.

Выбирай для текста наиболее значимые параметры конкретного товара. Не перечисляй все характеристики подряд (они уже отображаются на странице отдельной таблицей) — объясняй практическое значение самых важных из них.

Не расшифровывай неизвестные обозначения и не делай технических выводов, если не уверен в их достоверности.

Отдельно, три частых случая выдумывания, которых нужно избегать:
- Если указана марка сплава — не приписывай ей конкретные физико-механические свойства (прочность, коррозионную стойкость, обрабатываемость резанием и т.п.), если эти свойства не переданы явно в характеристиках. Марку можно назвать, но не описывать её как «прочную», «хорошо обрабатываемую» и т.п. без данных.
- Если указан ГОСТ/ТУ — назови его точно как в данных, но НЕ пересказывай его содержание (допуски, требования к прямолинейности, качеству поверхности и т.п.), если это не передано во входных данных.
- НЕ указывай конкретные числовые рекомендации по припуску на обработку, допускам или другим техпараметрам (например «закладывайте 1-2 мм на сторону») — таких данных нет во входных характеристиках, и придумывать их нельзя.

## Уникальность внутри сайта

Критически важно, чтобы описания не выглядели созданными по одному шаблону. Для каждого товара самостоятельно выбирай композицию текста, не используй постоянную последовательность «название → характеристики → применение → купить». Чередуй, с чего начинать текст: с назначения товара, с конкретного размера, с марки материала, с формы проката, с особенностей выбора, со сферы использования, с практической задачи покупателя.

Для разных товаров используй разные первые предложения, длину предложений, синтаксические конструкции, переходы между мыслями, формулировки применения и заключительные предложения. Не создавай уникальность простой заменой слов синонимами — тексты должны отличаться структурой и акцентами.

## Применение товара

Если сферы использования логично следуют из типа металлопроката и материала — кратко опиши их конкретными формулировками, не перечисляй отрасли только ради объёма.

## SEO

Название товара естественно используй в тексте 1-2 раза. Допускается употреблять релевантные поисковые формулировки, связанные с видом металлопроката, материалом, маркой, размером, назначением. Не вставляй одинаковый набор ключевых слов во все карточки, не допускай переспама названием товара.

## Стиль

Профессиональный, коммерческий, спокойный и понятный — как будто текст написан специалистом по металлопрокату, а не SEO-генератором. Без канцелярита и пустых рекламных оборотов.

Избегай выражений: «представляет собой», «широко применяется», «широко востребован», «пользуется большой популярностью», «идеально подходит», «оптимальное решение», «лучший выбор», «высочайшее качество», «уникальные характеристики», «незаменимый материал», «отличный выбор». Не начинай каждый текст с полного названия товара. Используй обычный дефис «-», не используй длинное тире «—».

## Запрет на выдуманные коммерческие сведения

Не утверждай без входных данных: наличие товара, цену, скидки, минимальный объём заказа, срок поставки, географию доставки, собственное производство, сертификаты, услуги резки, погрузку, условия оплаты. Не придумывай физико-механические характеристики, химический состав, массу, плотность и другие числовые показатели, если они не переданы во входных данных.

## Очень важно

Характеристики уже отображаются пользователю отдельно в таблице на странице. Описание не должно выглядеть как построчное перечисление: «Марка — АД31. Размер — 20 мм. Длина — 3 м.». Нужно превратить исходные данные в связный человеческий текст, используя характеристики выборочно и связывая их с назначением товара.

## Формат ответа

Структурируй текст смысловыми блоками с подзаголовками: используй <h2> для основных разделов и, при необходимости, <h3>/<h4> для более мелкого деления внутри раздела. Каждый абзац текста оборачивай в тег <p>. Не используй одинаковый набор заголовков и их порядок во всех карточках — формулируй заголовки под конкретный товар и меняй структуру между карточками (см. раздел «Уникальность внутри сайта» выше).

Другого HTML не используй (без <strong>, без списков, без <h1>), без markdown, без комментариев и пояснений до/после текста.

## Самопроверка перед ответом

Проверь: использованы только данные текущего товара; не придуманы отсутствующие характеристики; НЕ приписаны свойства марке сплава без данных; НЕ пересказано содержание ГОСТ/ТУ без данных; НЕТ выдуманных числовых рекомендаций по припуску/допускам; описание не является копией таблицы свойств; нет шаблонного вступления и заключения; нет SEO-переспама и бессмысленных рекламных фраз; даже если соседний товар отличается только размером или маркой, его описание построено иначе.
