# 1stall.ru — AI-генерация описаний товаров и SEO-страниц

Инструмент для автоматической генерации уникальных описаний товаров и SEO-текстов
страниц умного фильтра на 1stall.ru (Bitrix, шаблон Aspro Allcorp3 Metal) через Claude API
(router.cheap).

## Структура репозитория

```
server/   — PHP CLI-скрипт, который выполняется НА СЕРВЕРЕ 1stall.ru (через SSH)
gui/      — Windows GUI-клиент (Tkinter), которым управляют генерацией с локального ПК
prompts/
  products/    — промпты для товарных карточек, по типам продукции
  smartfilter/ — промпт для SEO-страниц умного фильтра
docs/     — ТЗ и отчёты по проекту
```

## Как это работает

1. GUI-клиент (`gui/ai_desc_gui_1stall.py`) запускается на рабочем ПК, подключается по SSH
   к серверу 1stall.ru и удалённо запускает `server/ai_generate_descriptions_1stall.php`
   с нужными аргументами (раздел, режим товары/SEO-страницы и т.д.).
2. PHP-скрипт на сервере обращается к Claude API (ключ передаётся через переменную
   окружения `ROUTER_CHEAP_API_KEY`, GUI прокидывает её при запуске команды), читает
   промпт из `prompts/`, генерирует текст и сохраняет отчёт в
   `ai_desc_report_section_{ID}.json` / `ai_ocfilter_report_batch_{ID}.json`.
3. После проверки отчёта содержимое применяется в Bitrix (запись в свойства
   iblock-элементов / EWP "CEO ЧПУ" iblock 51 для SEO-страниц).

## Установка на сервере

1. Склонировать репозиторий в отдельную папку рядом с корнем сайта (НЕ внутрь
   `/bitrix/`, чтобы не конфликтовать с ядром):
   ```
   git clone <URL репозитория> /home/web/1stall.ru/ai-content
   ```
2. Файл `server/ai_generate_descriptions_1stall.php` использует
   `require($_SERVER["DOCUMENT_ROOT"]."/bitrix/modules/main/include/prolog_before.php")`,
   поэтому должен выполняться из-под пользователя `web` на PHP 8.2 (см. заметки в
   `docs/`), при этом сам скрипт может физически лежать вне `DOCUMENT_ROOT`.
3. Папка `prompts/` должна быть доступна на запись (`chmod`/владелец `web`) — туда
   сохраняется `mapping.json` (соответствие раздела и файла промпта), когда вы
   назначаете промпт разделу через GUI.
4. Ключ API нигде в репозитории не хранится — передаётся только через переменную
   окружения при запуске (см. `.gitignore`: `config.json` с логином/паролем/ключом
   никогда не коммитится).

## Установка GUI-клиента (Windows)

1. Установить Python 3.x и `pip install paramiko`.
2. Скопировать/клонировать папку `gui/` на рабочий ПК.
3. Запустить `python ai_desc_gui_1stall.py`, ввести SSH-хост/логин/пароль и ключ
   router.cheap API в интерфейсе, сохранить настройки — они лягут в `config.json`
   рядом с `.py` (этот файл в `.gitignore`, наружу не публикуется).

## Обновление после правок

Дальше вместо ручной пересылки файлов через SFTP можно просто:
```
git pull
```
на сервере (в папке репозитория) и `git pull` / скачивание новых файлов на рабочем
ПК для GUI — см. пошаговую инструкцию по настройке в переписке с Claude.

## Безопасность

- `config.json` (GUI) и любые файлы с реальными паролями/ключами — никогда не
  коммитятся (см. `.gitignore`).
- Рекомендуется **приватный** репозиторий на GitHub — код содержит бизнес-логику
  генерации контента и структуру промптов, которые не предназначены для публикации.
